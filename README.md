# Calendar-App-Alpha-1
Proposal: Many calendar applicatoins are too complex or too rigid when it comes to customization. Users may find it difficult to navigate an overly complicated user interface, and they may even struggle to use it due to the sheer number of available features. In the end, such calanders do not offer any benefits for their users. This is where our application shines, as it provides users with a simplified, customizable calendar. The user interface is easy to navigate, allowing the user to easily organize their schedule without getting lost in the process. At the same time the user is able to customize their calendar and change backgrounds according to their preference. 

App Name	Booked & Busy
App Type	Calendar App that allows its users to organize their day-to-day lives.

Page 1 — Miliani - year	Shows an overview of the year, including each month.

Page 2 —Shay - month	Shows a detailed view of a single month, where users can view a single month,
where users can view and manage events across specific dates.

Page 3 — Noa - week	Shows a detailed view of a single week a month, where users can add their
personal tasks and tasks that they have with other members.

Page 4 — Day	Focuses on a single day, allowing users to view, add, and manage specific tasks
or events for that day.

Key Interactive Feature 1
Switchable Views 	Users can click to switch between different calendar views depending on how
detailed they want their schedule.

Key Interactive Feature 2
Add & Edit Events	Users can click on a date or time slot to add, edit, or delete events easily.

Key Interactive Feature 3
Customizable Backgrounds	Users can change the background/theme of their calendar to match their
personal style.

Key Interactive Feature 4
Simple Navigation Bar	Users can quickly move between pages (year, month, week, day) using a clean
navigation menu.
